Permission colors for files, folders and messages
Hacker prompt and green-on-black color scheme

Install
Run these one by one in Termux:
pkg update -y && pkg install git -y
git clone https://github.com/X7Shafin/Gost-Animation
cd Gost-Animation
bash 7xShafinb.sh
Then close Termux completely and open it again.
Colors
White = allowed, you can enter
Red = denied, you cannot enter
Yellow = no permission, you can do nothing
Green = normal text
Commands
Command
What it does
banner
Shows the banner again
cls
Clears the screen and shows the banner
x7legend
Shows the color meanings
x7off / x7on
Turns the animation off / on
gx <command>
Runs any command with the animation
ls / ll
Lists files with permission colors
Update
cd Gost-Animation && git pull && bash 7xShafinb.sh
