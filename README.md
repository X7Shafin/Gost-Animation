## Install

```bash
pkg update -y && pkg install git -y
```
```bash
git clone https://github.com/X7Shafin/X7Shafin
```
```bash
cd X7Shafin
```
```bash
bash 7xShafinb.sh
```

Then close Termux completely and open it again.

## Colors

- White = allowed, you can enter
- Red = denied, you cannot enter
- Yellow = no permission, you can do nothing
- Green = normal text

## Commands

- `banner` shows the banner again
- `cls` clears the screen and shows the banner
- `x7legend` shows the color meanings
- `x7off` / `x7on` turn the animation off / on
- `gx <command>` runs any command with the animation

## Update

```bash
cd X7Shafin && git pull && bash 7xShafinb.sh
```
